Create Manual Upload Link
Send a temporary link to a user when you want them to upload their own Excel.
How the Link Works
No account password is shared with the user.
1. Admin chooses the exact user + shop.
2. System generates a signed, expiring link.
3. User uploads Excel through that link and selects EAN / quantity headers.
4. Submission is saved against the selected user + shop.
5. The link expires automatically.
