Master Manual Upload Link
One permanent link for all users and shops. No separate link generation is required.
Use one link everywhere. The uploader enters their registered email and assigned shop on the upload page. The system validates the email/shop mapping before accepting the file.
How the Master Link Works
Simple for users, controlled by the mapping.
1. Share the same master link with everyone.
2. User enters registered email + assigned shop.
3. System validates the mapping.
4. User uploads Excel / CSV / PDF.
5. Original file is saved to Google Drive and submission is logged.
