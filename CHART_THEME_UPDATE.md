# Chart Theme Update

The chart layer was refined to use a restrained analytical palette rather than highly saturated brand colors.

Changes:
- Primary chart color: muted RENÉE pink
- Secondary series: neutral grey
- Comparison series: muted blue
- Positive/negative growth: muted green / muted red
- Reduced chart label and axis visual weight
- Softer gridlines and axes
- Dark, restrained tooltips
- Reduced bar visual density
- Softer line thickness and points
- Pie chart borders/labels softened
- Centralized chart normalization in `static/app.js` so future charts inherit the same visual language

The application business logic and data calculations were not intentionally changed by this theme-only refinement.
